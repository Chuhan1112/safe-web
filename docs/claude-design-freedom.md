# 给设计方的回复：放开约束 —— 图标 / 配色 / 风格可以重做

> 之前那份"设计系统种子"是把现有实现当基准抄给你，目的是先跑通、别跑偏。
> 现在明确放开：**不要被现有实现绑住。** 但下面第二节那几条不是风格偏好，是不能动的语义。

## 一、放开的范围（这些都可以重做）

- **图标**：整套可以重做 —— 风格、线宽、视觉重量、甚至换一套图标语言。
- **配色**：三主题全套重新定义。现有的青/蓝 primary、橙 accent、chart-1..6 序列色**都不是约束**。
- **字体**：可以换。界面字体和数字字体都可以换家族。
- **形状与质感**：圆角、阴影、边框、玻璃态面板、网格背景、噪点 —— 可以砍掉，也可以换成另一套语言。
- **动效**：时长与缓动词汇可以重新定义。
- **布局细节**：图标栏宽度、市场开关位置、信息密度的分布，都可以重做。

## 二、不可动的语义不变量（这四条是正确性，不是风格）

1. **涨跌色必须是市场感知的，由顶部 US / CN 开关翻转。**
   具体色值随你换，但机制不能取消，也不能把红/绿写死成"涨/跌"。
   这是这个产品最容易出错的地方：同一份界面，美股用户看到绿涨，A 股用户看到红涨。

2. **数字必须等宽、右对齐、`tabular-nums`。**
   字体家族随你换（换成别的等宽字体完全可以），但"等宽 + 右对齐 + 数字不抖动"这条不能丢。
   这是一个会同时显示 8 列数字的密集表格，比例字体会直接毁掉它的可读性。

3. **颜色语义不许复用。** 涨/跌 ≠ 危险/告警 ≠ 操作方向（买/卖）。
   重做配色时请给它们**各自独立的色位**：
   - `up` / `down` —— 市场方向，随市场翻转
   - `danger` —— 失败、错误
   - `warn` —— 熔断中、暂停开仓、数据陈旧
   - 操作方向（买/卖）用中性底 + 描边，不占用上面任何一色
   这四个如果共用一个颜色，语义就会互相污染（之前已经踩过一次：`accent` 在某个主题下变成青色，"熔断"的警示语义就丢了）。

4. **长时间阅读的对比度下限。** 默认暗色、一天开八小时。
   正文与背景的对比度不能低于现有实现（暗色下 foreground 210 24% 93% / background 220 40% 8%）。

另外：**信息密度不能退化。** "表格是主角、层级靠间距/边框/字重"是产品定位，不是可以牺牲的风格偏好。

## 三、现在请你来定义 token（不要再照抄我给的那套）

输出一份完整、可直接落地的 token 表：

- **三主题**：light / dark / perplexity。如果你认为 perplexity 应该砍掉或换成别的，说明理由 —— 那是产品决策，我来拍板，但请提出你的看法。
- **每个主题给全**：表面层（background / card / popover / border / input）、文字层（foreground / muted-foreground）、语义色位（primary / accent / up / down / danger / warn / info）、图表序列色 6 个。
- **图表 6 色**：在暗色下彼此可区分，且不能与 up / down / danger 撞色 —— 回测页要同时画最多 6 条策略曲线。
- **格式**：`--token: H S% L%`（HSL 三元组，不带 `hsl()` 外壳）。我按这个格式直接写进代码，不用再转换。
- 附一份"哪个 token 用在哪"的对照说明（例如：表头文字用哪个、表格斑马纹用哪个、描边按钮的 hover 用哪个）。

## 四、实现成本（让你有意识地选，不是叫你省）

| 改动 | 代码代价 |
|---|---|
| 换配色值 | **低** —— 三个主题块 |
| 换涨跌色值 | **低** —— 改变量即可；机制集中在一个 hook 里，不用动 |
| 增删主题 | **低** |
| 换图标*风格*（不换库） | **低** —— 统一线宽/尺寸/去装饰即可 |
| 换字体家族 | **中** —— 3 处要同步 |
| 换动效词汇 | **中** —— 3 处要同步 |
| 换图表序列色 | **中** —— 变量 + 一个集中定义文件 + 一个会拦住不一致的测试 |
| 换图标*库* | **高** —— 28 个文件、115 处引用、56 个不同的图标（机械替换，但量大） |

结论：**配色、风格、图标风格、形状、动效 —— 随便改，我这边都能落地。**
唯一需要你给个明确理由的是"换图标库"，因为它是一次跨 28 个文件的机械替换。
