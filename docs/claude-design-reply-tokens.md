【答复 1：warn】
确认它是独立色位，不要和 accent 绑。dark 起点用 `24 94% 58%` 可以，但请给它一个**语义定义**：
熔断中 / 暂停开仓 / 数据陈旧。而不是"与 accent 同值"—— accent 一调整，warn 必须能独立走。

【答复 2：info】
不用你拟，代码里已有事实值（某处提示组件的 info 变体用的就是这组）：
- 基准 `199 89% 48%`
- light 文字 `201 96% 32%`
- dark 文字 `198 93% 60%`

它有真实用途：提示条的 info 变体、状态徽标、任务"运行中"状态、以及"好但不是涨"的指标（例如夏普比率）。
**原则：不要为了凑齐 token 表而造没有用途的色位。** 现有代码里就有一个反面教材 —— 有一个市场色变量定义了但全仓 0 处引用。
