【一、设计系统】

风格定位：专业、冷静、信息优先的"研究控制台"，不是消费级金融 App。
参考质感：Bloomberg Terminal 的信息密度 + Linear/Arc 的克制。
这是同一个人每天开一整天的工具，不是给人浏览一次的落地页。

主题：light / dark / perplexity（暖调深棕、低蓝光阅读档）三套，由同一套 CSS 变量驱动；默认 dark。
配色一律用下面的 token，不要自己挑 hex：
- dark  : background 220 40% 8% / card 220 39% 11% / border 216 24% 24%
          foreground 210 24% 93% / muted-foreground 214 16% 66%
          primary 184 83% 53%（青）/ accent 24 94% 58%（橙）/ destructive 0 70% 45%
- light : background 0 0% 98% / card 0 0% 100% / border 0 0% 89.8%
          foreground 0 0% 20% / primary 207 100% 45%（蓝）/ accent 24 96% 53%（橙）
圆角：lg 10px / md 8px / sm 6px。主工作区最大宽度 1680px。

涨跌色是"市场感知"的，这是本项目最重要的视觉规则：
- 美股：绿涨红跌；A 股：红涨绿跌。
- 不要把红/绿写死为"跌/危险"；红绿语义由顶部的 US / CN 开关翻转。
- data-up 135 78% 39%，data-down 0 84% 60%，CN 模式下互换使用。
- 市场标识色：US #1d4ed8（蓝），CN #dc2626（红）。
- 图表多序列色共 6 个（chart-1..6），用于多策略对比。

字体：界面用 Inter；所有数字（价格、收益率、权重、日期、标的代码）用 JetBrains Mono 等宽。
数字排版规则全站统一：等宽 · 右对齐 · 千分位 · 显式正负号 · 收益率 2 位小数 · 权重 1 位小数。
另有一个 10px 小号档，专用于表格中的次要标签。

动效词汇（沿用，不要自创）：
- 时长：press 90ms / snap 140ms / move 220ms / enter 280ms
- 缓动：ease-snap(0.2,0.8,0.2,1)、ease-spring(0.34,1.32,0.44,1)、ease-liquid(0.32,1.5,0.5,1)
- 基调：快、短、有落点。只用来表达状态变化（数字滚动、抽屉滑入、行高亮），不做装饰性动画。

质感元素（现状）：扁平玻璃面板（半透明 + 1px 边框 + 柔和投影）。注：safe 区当前**没有**光晕、网格背景和噪点（那是我早先的笔误）。

【二、产品】

量化策略研究工作台：给个人量化研究者用的"策略研究 + 盘中监控"控制台，
把跑回测、看信号、查数据质量、比实验收进同一个数据密集的工作区。
用户：1 个专业用户，每天打开，月度调仓；熟练用户，不需要引导教程。
环境：macOS 桌面浏览器，1440–1920px 宽，暗色为主，常驻开一整天。

最重要的 3 件事（按优先级）：
1. 今天该不该动手？—— 信号：今日目标持仓、买卖动作、风险状态
2. 策略最近怎么样？—— 回测：净值曲线、回撤、指标、交易日志
3. 数据可信吗？—— 数据健康：新鲜度、缺口、异常

信息架构：左侧 64px 图标栏（w-16），主工作区单页切换、无路由跳转。
导航：回测 · 优化 · 健康 · 实验 · 信号 · 分析 · 研究 · 筛选 · 打分 · 数据
全局控件：市场开关（US / CN）、主题开关（light / dark / perplexity）、日期范围（带快捷预设）。

交互硬约束：
- 切 tab 用 CSS 隐藏而不是卸载；后台长任务（优化、全市场扫描）不能因为切页而中断。
- 表格是主角：可排序表头、粘性首列、行内点击进入标的详情。
- 详情一律用右侧抽屉，不用新页面，保持上下文。
- 每个异步区域都要骨架屏；空状态必须给出明确的下一步动作。
- 长任务要能看到进度、可中止、可回看历史。
- 层级用间距 / 边框 / 字重表达，不要堆颜色。
